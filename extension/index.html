설치 방법

  1. ZIP 파일의 압축을 풀어 주세요

    Windows는 파일을 오른쪽 클릭해 ‘모두 압축 풀기’, Mac은 ZIP 파일을 더블 클릭하세요.

    압축을 푼 폴더는 설치 후에도 지우거나 옮기지 마세요.

  2. Chrome의 확장 프로그램 관리 화면을 여세요

    새 Chrome 탭의 주소창에 붙여넣으세요.

  3. 오른쪽 위 ‘개발자 모드’를 켜세요

    왼쪽 위의 ‘압축해제된 확장 프로그램을 로드합니다’ 버튼을 누르세요. 영문 Chrome에서는 ‘Load unpacked’입니다.

  4. 압축을 푼 폴더를 선택하세요

    manifest.json 파일이 바로 들어 있는 폴더를 선택하세요. ZIP 파일 자체나 그 상위 폴더를 선택하면 설치되지 않습니다.

  5. 아실을 열고 새로고침하세요

    이미 열어 둔 아실 탭도 새로고침하세요. 지원 화면에서 빠른 검색 패널을 사용할 수 있습니다.

어디에서 쓰나요?

  • 순위분석 · 최고가 순위

    지역 검색으로 시·도부터 읍·면·동까지 선택 단계를 줄입니다.

  • 인구변화 · 입주물량

    화면에서 지원하는 지역 단계까지 빠르게 선택합니다.

  • 아파트 비교

    지역 선택 후 해당 동의 단지명을 검색해 선택합니다. 면적 선택과 ‘추가’는 아실에서 직접 진행하세요.

  • 지도 지역 선택

    현재 열린 목록 검색과 확인된 관양동 이동을 지원합니다. 전국 지도 검색은 아직 제공하지 않습니다.

최근 선택 기록과 패널 위치는 이 Chrome에 저장됩니다. 아실 화면 변경에 따라 동작하지 않을 수 있습니다.

패널이 안 보인다면

확장 관리 화면에서 ‘아실 빠른 검색’이 켜져 있는지 확인한 뒤, 아실을 새로고침하세요. 지도에서는 지역 선택 목록을 열고, 비교에서는 비교 화면으로 이동해 보세요.

업데이트 · 삭제

새 ZIP을 내려받아 기존 설치 폴더의 내용을 교체한 뒤, 확장 관리 화면의 새로고침(↻)과 아실 새로고침을 차례로 누르세요. 자동 업데이트는 제공하지 않습니다.

삭제는 확장 관리 화면의 ‘삭제’ 버튼을 이용하세요. 삭제하면 확장에 저장한 최근 선택 기록과 위치 설정도 지워집니다.

권한과 데이터

아실(asil.kr) 화면의 지역·단지 목록을 읽고 선택하며, 최근 선택 기록과 패널 위치를 브라우저에 저장합니다. 개발자 서버로 검색어나 기록을 보내지 않습니다.

아실 자체 기능을 실행할 때 발생하는 아실과의 통신은 해당 사이트 정책을 따릅니다. 아실 공식 제품이나 제휴 서비스가 아닙니다.
